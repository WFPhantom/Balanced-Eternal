# Balanced Eternal

> What makes me a good modpack? If I were a bad modpack, I wouldn't be sittin' here, discussin' it with you now would I?

Neoforge: 21.1.219

Issue tracker and source for [Balanced Eternal](https://www.curseforge.com/minecraft/modpacks/balanced-eternal), a Minecraft modpack.

This branch is the updated version of BE that is currently heavily WIP and not recommended for survival. If you want to test it out feel free to download the [latest release](https://github.com/WFPhantom/Balanced-Eternal/releases/tag/1.0.0-alpha.10) and use InstanceSync. Please report any issues you encounter after making sure they are not listed on the [Project Board](https://github.com/users/WFPhantom/projects/4)

Make sure to do regular backups and practice good modding skills.
