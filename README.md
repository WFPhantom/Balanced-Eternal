# Balanced Eternal

Neoforge: 21.1.212

Issue tracker and source for [Balanced Eternal](https://www.curseforge.com/minecraft/modpacks/balanced-eternal), a Minecraft modpack.

The 1.21.1 branch is heavily WIP and does not work as intended. If you want to test it out feel free to download the [latest release](https://github.com/WFPhantom/Balanced-Eternal/releases/tag/1.0.0-alpha.9) and use InstanceSync. Please report any issues you encounter after making sure they are not listed on the [Project Board](https://github.com/users/WFPhantom/projects/4)

Make sure to do regular backups and practice good modding skills.
